# 📁 Section 10: Projects (`sections/10-projects/`)

Folder ini mengatur kartu-kartu showcase proyek pengembang (Portfolio, Website Pertama, Landing Page).

## 📄 Berkas di Folder ini:
1. **`projects.html`**: Markup HTML kartu proyek dengan tag teknologi dan tombol aksi.
2. **`content.json`**: Data judul proyek, deskripsi, tag, URL live demo, dan URL source code.

## ✏️ Cara Mengedit:
- **Mengubah Judul Proyek**: Edit teks pada `<h3 class="dev-project-title" id="live-proj-1-title">`.
- **Mengubah Deskripsi Proyek**: Edit teks pada `<p class="dev-project-desc" id="live-proj-1-desc">`.
- **Mengubah Status Proyek**: Edit teks pada `<span class="dev-version-pill">Production</span>`.
- **Mengubah Link Live/Source**: Ganti URL pada `<a href="..." class="btn-project-action">`.
- **Menambah Proyek Baru**: Salin blok `<div class="dev-project-card tilt-card-3d">...</div>` dan sesuaikan isinya.
