# 📁 Section 05: Integrations (`sections/05-integrations/`)

Folder ini mengatur kartu-kartu ekosistem teknologi dan perangkat (HTML5, CSS3, JavaScript, GitHub, Figma, VS Code).

## 📄 Berkas di Folder ini:
1. **`integrations.html`**: Markup HTML grid kartu teknologi.
2. **`content.json`**: Data teks judul, nama tool, peran, dan ikon Boxicons.

## ✏️ Cara Mengedit:
- **Mengubah Judul/Deskripsi**: Edit teks pada `id="live-integrations-title"` dan `id="live-integrations-desc"`.
- **Menambah/Mengganti Teknologi**:
  - Salin blok `<div class="integration-card tilt-card-3d">...</div>`.
  - Ubah class ikon (misal: `bx bxl-react`), nama `<div class="integration-name">`, dan peran `<div class="integration-role">`.
