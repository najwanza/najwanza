# 📁 Section 13: Footer (`sections/13-footer/`)

Folder ini mengatur footer situs dengan navigasi cepat dan teks copyright.

## 📄 Berkas di Folder ini:
1. **`footer.html`**: Markup HTML footer dengan link navigasi dan copyright.
2. **`content.json`**: Data teks copyright dan daftar link footer.

## ✏️ Cara Mengedit:
- **Mengubah Teks Copyright**: Edit teks pada `id="live-footer-copy"`.
- **Menambah/Mengubah Link Footer**: Edit elemen `<li><a href="...">Label</a></li>` dalam `<ul class="dev-footer-links">`.
- **Mengubah Link GitHub**: Ganti URL pada `<a href="https://github.com/Zakyyii">`.
