# 📁 Section 07: Education (`sections/07-education/`)

Folder ini mengatur timeline riwayat perjalanan akademik (Universitas Negeri Surabaya, SMAN 1 Pandeglang, SMPN 2 Karang Tanjung, SDN Pagadungan 01).

## 📄 Berkas di Folder ini:
1. **`education.html`**: Markup HTML kartu-kartu timeline pendidikan.
2. **`content.json`**: Data nama institusi, jurusan/program, rentang tahun, dan logo.

## ✏️ Cara Mengedit:
- **Mengubah Nama Sekolah**: Edit teks pada `<h4>` (misal: `id="live-edu-1-title"`).
- **Mengubah Jurusan/Program**: Edit teks pada `<div class="dev-timeline-major">` (misal: `id="live-edu-1-major"`).
- **Mengubah Rentang Tahun**: Edit teks pada `<span class="dev-version-pill">2026 - 2030</span>`.
- **Mengubah Logo Sekolah**: Ganti path gambar pada `<img src="assets/images/..." alt="...">`.
