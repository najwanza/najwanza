# 📁 Section 04: Comparison Matrix (`sections/04-comparison/`)

Folder ini mengatur tabel matriks perbandingan fitur & kapabilitas frontend pengembang vs metode konvensional.

## 📄 Berkas di Folder ini:
1. **`comparison.html`**: Kode HTML tabel matriks perbandingan.
2. **`content.json`**: Data teks judul, deskripsi, dan baris fitur.

## ✏️ Cara Mengedit:
- **Mengubah Judul & Deskripsi Section**: Edit teks pada `id="live-comparison-title"` dan `id="live-comparison-desc"`.
- **Menambah/Mengedit Baris Fitur**:
  - Di dalam `<tbody>`, edit teks pada `<div class="feature-title-cell">` dan `<div class="feature-desc-muted">`.
  - Ubah status kolom tengah (`Najwan Zaki`) atau kolom kanan (`Conventional Frontend`).
