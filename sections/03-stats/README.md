# 📁 Section 03: Stats (`sections/03-stats/`)

Folder ini mengatur 4 kartu ringkasan angka statistik yang memiliki animasi perhitungan otomatis saat muncul di layar.

## 📄 Berkas di Folder ini:
1. **`stats.html`**: Kode HTML kartu counter statistik.
2. **`content.json`**: Nilai target angka (`countTo`), akhiran simbol (`suffix`), dan label.

## ✏️ Cara Mengedit:
- **Mengubah Angka Target Animasi**: Edit atribut `data-count-to="10"` pada `<div class="dev-stat-number">`.
- **Mengubah Simbol Tambahan**: Edit atribut `data-suffix="+"` (misal: `+`, `%`, `±`).
- **Mengubah Label Teks**: Edit teks pada `<div class="dev-stat-label">Label Anda</div>`.
