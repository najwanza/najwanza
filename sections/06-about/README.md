# 📁 Section 06: About Me (`sections/06-about/`)

Folder ini mengatur informasi profil pengembang, foto avatar portrait, biografi ringkas, dan alasan memilih Sistem Informasi.

## 📄 Berkas di Folder ini:
1. **`about.html`**: Kode HTML kartu profil bento.
2. **`content.json`**: Data teks nama, biografi, aspirasi karir, dan paragraf filosofi.

## ✏️ Cara Mengedit:
- **Mengubah Foto Profil**: Ganti path gambar pada `<img id="live-about-photo" src="...">`.
- **Mengubah Nama & Role**: Edit teks pada `id="live-about-name"` dan `id="live-about-role"`.
- **Mengubah Bio**: Edit teks paragraf pada `id="live-about-bio"`.
- **Mengubah Paragraf Filosofi**: Edit teks pada `id="live-about-phil-title"`, `id="live-about-phil-1"`, dan `id="live-about-phil-2"`.
