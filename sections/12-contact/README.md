# 📁 Section 12: Contact (`sections/12-contact/`)

Folder ini mengatur informasi kontak (email, lokasi, Instagram) dan formulir pesan kolaborasi.

## 📄 Berkas di Folder ini:
1. **`contact.html`**: Markup HTML kartu info kontak dan formulir pesan.
2. **`content.json`**: Data email, lokasi, handle Instagram, dan teks kartu.

## ✏️ Cara Mengedit:
- **Mengubah Email**: Edit teks pada `id="live-contact-email"` dan `href="mailto:..."`.
- **Mengubah Lokasi**: Edit teks pada `id="live-contact-location"`.
- **Mengubah Instagram**: Edit teks pada `id="live-contact-instagram"` dan `href="https://..."`.
- **Mengubah Label Form**: Edit teks pada `<label class="dev-form-label">`.
- **Mengubah Placeholder Form**: Edit atribut `placeholder="..."` pada input/textarea.
