# 📁 Section 01: Navbar (`sections/01-navbar/`)

Folder ini berisi file untuk mengatur bagian navigasi atas (Navbar) website.

## 📄 Berkas di Folder ini:
1. **`navbar.html`**: Kode HTML struktur navbar.
2. **`content.json`**: Data teks murni navbar (nama brand, versi, menu navigasi).

## ✏️ Cara Mengedit:
- **Mengubah Nama Brand/Logo**: Edit teks `Zakyy.dev` atau versi `v2.4.0` di `navbar.html`.
- **Menambah/Mengurangi Menu**: Tambahkan atau hapus tag `<li><a href="#id-tujuan">Nama Menu</a></li>` di dalam `<ul class="dev-nav-links">`.
- **Mengubah Perintah CLI Cepat**: Ganti teks `npx najwan-zaki` di tombol `<button class="cli-pill-btn">`.
